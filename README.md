# FRACLAB

Makmal pecahan interaktif untuk murid sekolah rendah. Buka `index.html` dalam pelayar; tiada langkah build diperlukan.

Mod:
1. **Teroka** – bina sebarang pecahan dan lihat nilainya sebagai pecahan, nombor bercampur, perpuluhan, peratus dan garis nombor.
2. **Bercampur → Tidak wajar** – bina model jubin, kemudian tulis pecahan tidak wajar.
3. **Tidak wajar → Bercampur** – isi jubin satu demi satu; setiap jalur penuh menjadi satu nombor bulat.
4. **Banding** – bandingkan dua pecahan dengan jalur dan darab silang, termasuk pecahan setara.
5. **Kuiz** – 10 soalan rawak dengan markah, rentetan dan rekod terbaik.

Ciri lain: BM/EN, bunyi, mod gelap/cerah ikut sistem, seret untuk mengisi jubin (tetikus atau sentuhan), pintasan papan kekunci 1–5.
